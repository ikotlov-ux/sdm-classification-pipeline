# common/ — общая часть пайплайнов

Этап подготовки предикторов, который используется **обеими ветками** — и классификацией, и SDM.

## 00_Prepare_Layers.py

Собирает многослойный композит из мультисенсорных данных.

**Входные источники:**
- Sentinel-2 (SR/TOA)
- Landsat 5/7/8/9
- MODIS (NDVI, snow cover)
- Sentinel-1 (VV, VH)
- ALOS PALSAR (HH, HV)
- ЦМР + производные (WhiteboxTools: HAND, CHILI, TPI, landforms и т.п.)

**Что делает:**
1. Выравнивает все растры на общую опорную сетку (единая проекция, разрешение, экстент).
2. Считает спектральные (`spyndex`), радарные и морфометрические индексы.
3. Собирает единый композит `Composite.tif`.
4. Фильтрует слои с нулевой/околонулевой дисперсией → `Composite_filtered.tif`.
5. Сохраняет список имён предикторов в `predictor_names.pkl`.

**Ключевые параметры/переменные (внутри скрипта):**
- `GDAL_CACHEMAX=4096` — крупный кэш GDAL для эффективной работы с многослойными Sentinel-2-стеками.
- `zstd_level=1` для временных aligned/reproj GeoTIFF (в 2–3 раза быстрее записи ценой большего временного размера).
- TEMP-папка выносится за пределы синхронизируемых облачных каталогов (например, `I:\TEMP_terra_align`).

**Выходы, потребляемые дальше:**
| Файл | Куда идёт |
|---|---|
| `Composite_filtered.tif` | `classification/01_prepare_data.py`, `sdm/01s_prepare_sdm.py` |
| `predictor_names.pkl` | обе ветки — синхронизация имён слоёв |

## Дальнейшая развилка

- **Классификация** → `classification/01_prepare_data.py`: извлекает значения предикторов в **пикселях полигонов** обучающих участков.
- **SDM** → `sdm/01s_prepare_sdm.py`: извлекает значения в **точках присутствия** и генерирует **background** методом Gaussian KDE (bias-grid).
